# 破壳 (Pòké) — 微信小程序版

> 把刷不完的群消息，变成今天值得做的 3 件事。

这是 `poke-mvp`（网页原型）的**微信小程序**移植版，结构、逻辑、痛点映射完全一致，但用小程序的方式实现：WXML/WXSS 渲染、`wx.setStorageSync` 本地存储、原生底部 tabBar。

## 怎么运行

1. 安装 **微信开发者工具**（Stable 版即可）。
2. 打开 → **导入项目** → 目录选择本文件夹 `poke-miniprogram`。
3. AppID 选 **「测试号 / 不使用 AppID」**（项目里已设为 `touristappid`，可直接体验）。
4. 点击「编译」，模拟器里即可使用；真机预览扫码即可上手机。

> 若要正式发布，需在 `project.config.json` 把 `appid` 换成你自己的小程序 AppID。

## 目录结构

```
poke-miniprogram/
├── app.json            # 页面注册 + 底部 tabBar（今天/我的/复盘）
├── app.js / app.wxss   # 全局逻辑 / 全局样式
├── project.config.json # 开发者工具项目配置（touristappid 可直接跑）
├── sitemap.json
├── utils/store.js      # 状态、本地存储、示例数据、视图模型、认知问题
├── templates/card.wxml # 复用的卡片模板（今天 / 我的 共用）
└── pages/
    ├── today/          # 今天：精选 3 件事 + 🌱 破壳卡
    ├── mine/           # 我的：你主动标记的事
    ├── reflect/        # 复盘：30 秒认知小问题
    └── operator/       # 运营：录入条目 + 关键指标（从「今天」右上角进入）
```

## 三个 tab + 运营，对应你的痛点

| 位置 | 解决的痛点 | 说明 |
|---|---|---|
| **今天** | 信息过剩 / 聚合活动通知 / 信息茧房 | AI 风格筛过的「今日精选」+「破壳卡」（圈外内容），每条可「想去 / 找搭子」 |
| **我的** | 找搭子 | 你主动标记的事，把信息变成行动 |
| **复盘** | 提升认知 / 健脑 | 对你「去过」的事给一个认知小问题 |
| **运营**（今天页右上角） | — | 手动录入今天的条目 + 看关键指标（想去 / 找搭子 / 到场 / 复盘） |

## 接后端（真实 AI 数据）

小程序已内置网络层，可直接读 `poke-server` 的真 AI 数据，连不上则自动回退示例数据。

1. 先启动后端：在 `poke-server` 里 `npm install && npm start`（默认 http://localhost:5700）。
2. 打开 `poke-server` 控制台点「灌入样本」让库里有数据。
3. 开发者工具右上「详情 → 本地设置」勾选 **不校验合法域名**（http://localhost 才能请求）。
4. 小程序「今天」**下拉刷新**：标题会变「实时 · 真实 AI 数据」，机会/搭子 tab 也来自后端。
5. 真机/上线：把 `utils/config.js` 的 `API_BASE` 换成你的 **https 域名**（localhost 真机访问不到）。

> 后端地址配置在 `utils/config.js`；设为 `''` 即纯离线（示例数据）。

## 关于数据

- 每台设备首次打开会生成一个 `uid`（存本地），用于后端多人计数。
- **在线**时：「想去 / 找搭子 / 去过」全部写后端，`X 人想去` 是**多人真实计数**，会跨设备同步；「我的 / 复盘」也来自后端 `/api/me`。
- **离线**时：自动回退到本机示例数据 + 本机参与标记。
- 复盘文字（认知小记）始终存本机。
- 五个 tab：**今天**(活动通知聚合) · **机会**(雷达) · **搭子** · **复盘** · **我的**。

> 想验证"多人同步"：用两个微信开发者工具实例（或真机+模拟器）打开同一后端，在一个里点「想去」，另一个下拉刷新即可看到计数 +1。

## 真实验证（最重要）

工具不是重点。真正的 MVP 测试：选一个班/社团，用「运营」手动录入一周的活动通知，每天把小程序发到群里，只看一个数——**有多少人真的点了「想去」并且真的去了**。人会行动，再做真 AI agent + 后端。
